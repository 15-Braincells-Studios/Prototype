# Prevent the Murder — Block Prototype 1

Unity 6 (6000.3.23f1), URP, new Input System. First-person murder-mystery prototype: the player searches a castle
for clues, talks to NPCs and reports the would-be victim and culprit before the clock runs out.

## Layout
- `Assets/Scripts/` — all code, namespace `PreventTheMurder` (editor code: `PreventTheMurder.EditorTools`).
  - `Data/` ScriptableObject definitions (Character, Clue, Dialogue, Scenario).
  - `Game/` GameManager (state, countdown, binds scenario to scene), rooms, report points.
  - `Clues/`, `Dialogue/`, `Interaction/`, `NPC/`, `Player/`, `UI/` — runtime systems, singletons + C# events.
  - `Editor/CastlePrototypeBuilder.cs` — generates `Assets/Scenes/Castle_Prototype.unity` (menu: Tools > Prevent the Murder > Build Castle Prototype Scene). The scene is **generated**: change the builder, not the scene file.
  - `Editor/ScenarioAuthoring.cs` — generates the Vesper Bell assets in `Assets/Data/Scenarios/VesperBell/`. Spot ids are shared constants between both editor scripts.
- Scenes match data by string ids: character `id`, clue `spotId`, reporter id. Renaming an id means updating both sides.

## Conventions
- Match existing style: XML `<summary>` on classes, `[Tooltip]` on serialized fields, `[SerializeField]` private fields, events over direct calls, `[DefaultExecutionOrder]` for managers.
- Play never writes to assets (runtime state lives in plain classes like `DiscoveredClue`).
- Never hand-edit `.unity`, `.asset`, `.meta` YAML when an editor script or the Unity CLI can do it. Never touch `Library/`, `Temp/`, `Logs/`, `*.csproj`, `*.sln`.

## Separate prototype: Assassin Mystery
`Assets/AssassinMystery/` is a different, independent prototype ("The Vesper Toast", third-person). It must stay
isolated: own namespace `AssassinMystery`, own asmdefs, no references to or from `PreventTheMurder` code, data or
scenes. Everything above this section is about Prevent the Murder only. See `Assets/AssassinMystery/README.md`.

## Separate prototype: Blockout Murder Mystery
`Assets/BlockoutMystery/` is a third independent prototype (third-person primitive blockout: antidote on the right
plate, then report to the butler). The same isolation rules apply: namespace `BlockoutMystery`, own asmdefs, no
references to or from the other prototypes. It has five variants ("Blockout Murder Mystery - Speech Bubbles",
"- Subtitles", "- Visual Novel", "- Close-up Subtitles", "- Isometric Speech Bubbles"). They share all code and the
puzzle and differ only in camera and dialogue presentation (`PrototypeVariant`). Their scenes are generated by
`Editor/BlockoutSceneBuilder.cs` (Tools > Blockout Murder Mystery > Build All Variants). See
`Assets/BlockoutMystery/README.md`.
